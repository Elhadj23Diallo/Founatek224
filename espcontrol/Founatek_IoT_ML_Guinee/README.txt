FOUNATEK IOT + IA (GUINEE) - PACK ML

OBJECTIF
Former un modèle d'intelligence artificielle capable de décider automatiquement s'il faut irriguer une parcelle agricole.

CONTEXTE
- Pays : Guinée
- Cas réel : agriculture intelligente
- Données IoT simulées réalistes

CONTENU DU DOSSIER
- founatek_iot_guinee.csv : données IoT simulées
- train_model.py : script d'entraînement IA
- README.txt : ce fichier

UTILISATION (PythonAnywhere)
1. Upload tous les fichiers
2. Installer les dépendances :
   pip install pandas scikit-learn
3. Lancer :
   python train_model.py

PROCHAINE ETAPE
- Connecter Arduino
- Ajouter un dashboard IA
- Déployer dans Founatek
